EV Charging Demand Analytics

An interactive Power BI analytics project designed to analyze EV
charging demand, energy consumption, charging cost, vehicle behavior,
charger utilization, station performance, and location-level demand.



📊 Project Overview

The EV Charging Demand Analytics dashboard provides an interactive
view of EV charging network performance. It helps users understand
charging activity, energy demand, operational efficiency, vehicle
behavior, and station performance.

The dashboard includes bookmarks, filters, tooltips, drill-through
navigation, page navigation, and Row-Level Security (RLS).

📌 Dashboard Views

1. Executive Overview

High-level summary of the EV charging network through key KPIs and major
performance visuals.

Key metrics: Charging Sessions, Total Energy (kWh), Total Charging
Duration, Total Waiting Time, Total Charging Cost, and Average Charging
Power.

2. Charging Analysis

Focuses on charger utilization, charging demand, and operational
performance.

3. Vehicle Analysis

Analyzes charging behavior, energy consumption, charging duration, and
performance across Car, Two-Wheeler, and Bus categories.

4. Station & Location Analysis

Provides station-level and location-level analysis, including energy
demand, charging sessions, top stations, and station performance.

🎯 Project Objective

Transform EV charging data into an interactive analytical solution for
monitoring charging demand, energy consumption, charging cost, waiting
time, vehicle performance, charger performance, station performance, and
location-level demand.

🔐 Security

Row-Level Security (RLS) is implemented to control data visibility based
on configured user role and location access.

📖 User Guide

The USER GUIDE folder contains detailed instructions for dashboard
navigation, filters, tooltips, drill-through, bookmarks, RLS, settings,
notifications, and the complete dashboard usage flow.
