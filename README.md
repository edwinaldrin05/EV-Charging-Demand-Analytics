# EV Charging Demand Analytics

<img width="1920" height="1080" alt="Executive" src="https://github.com/user-attachments/assets/3c8c0b5b-2b85-49aa-981d-6a390653cdc7" />


An interactive **Power BI analytics project** designed to analyze EV charging demand, energy consumption, charging cost, vehicle behavior, charger utilization, station performance, and location-level demand.

## 📊 Project Overview

The **EV Charging Demand Analytics** dashboard provides an interactive view of EV charging network performance. It helps users understand charging activity, energy demand, operational efficiency, vehicle behavior, and station performance.

The dashboard includes **bookmarks, filters, tooltips, drill-through navigation, page navigation, and Row-Level Security (RLS)**.

## 📌 Dashboard Views

### 1. Executive Overview

Provides a high-level summary of EV charging network performance using key KPIs and visuals.

**Key metrics:**
- Charging Sessions
- Total Energy (kWh)
- Total Charging Duration
- Total Waiting Time
- Total Charging Cost
- Average Charging Power

### 2. Charging Analysis

Focuses on charger utilization, charging demand, and operational performance.

- Charging Mix by Charger Power
- Charging Demand Pattern
- Charging Activity vs Energy Consumption
- Charging Performance by Charger ID
- Station Charging Operations

### 3. Vehicle Analysis

Analyzes charging behavior, energy consumption, charging duration, and performance across:

- Car
- Two-Wheeler
- Bus

### 4. Station & Location Analysis

Provides station-level and location-level analysis.

- Location Energy Share
- Charging Sessions by Location Type
- Top Charging Stations by Energy
- Energy Demand by Location Type
- Station Performance

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development, visualization, navigation, reporting, and RLS
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and analytical calculations
- **SQL** – Data querying and analysis
- **Excel / CSV** – Source data and supporting datasets

## ⚙️ Interactive Features

- **Bookmarks** – Used for page navigation and interactive panels
- **Filters** – Filter data by Date, Vehicle, and Location
- **Tooltips** – Display additional information when hovering over visuals
- **Drill-through** – Move from summary information to detailed analysis
- **Page Navigation** – Navigate between dashboard analysis pages
- **RLS** – Controls data visibility based on user access
- **Settings Panel** – Executive View, Detailed View, Reset Filters, and About Dashboard
- **Notifications** – Displays predefined network alerts
- **User Profile** – Shows current user, role, location access, and RLS status
